# 국가자격시험 AI 학습 프로그램

브라우저에서 바로 쓰는 국가자격시험(건설안전 등) 학습용 단일 HTML 앱입니다.

## 사용법

1. 아래 사이트를 엽니다.  
   **https://ahnws0722-hub.github.io/exam-ai-study/**
2. 왼쪽(모바일에서는 위)에서 자격·과목을 고른 뒤 플래시카드·객관식·서술형·모의고사 등을 이용합니다.
3. 학습 기록은 **이 기기의 브라우저(로컬 저장소)** 에만 남습니다. 다른 기기와 자동 동기화되지 않습니다.

## 아이폰 홈 화면에 추가

1. Safari로 위 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 선택합니다.
3. 홈 화면 아이콘으로 앱처럼 실행할 수 있습니다.

## 주간 내용 추가

작업 복사본: `/workspace/exam-ai-study/index.html`  
수정 후 이 저장소 `main` 브랜치에 푸시하면 GitHub Pages가 갱신됩니다.
